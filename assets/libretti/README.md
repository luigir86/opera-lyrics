# Libretti

Every `.txt` file in this folder is an opera in the library: adding an opera means adding a file here, nothing else. The format is in [docs/formato-libretti.md](../../docs/formato-libretti.md).

The texts are in the public domain (their authors died more than 70 years ago). Each file says in its header where its text comes from (`source:`) and under which terms that transcription is shared (`license:`). Transcriptions from Wikisource are shared under CC BY-SA 4.0: they keep that licence and their attribution, separate from the app's code, which is under the MIT License.

The file name is `composer-title.txt` in lower case, with hyphens: `verdi-la-traviata.txt`. It is also the libretto's id, so it should not change once published.
